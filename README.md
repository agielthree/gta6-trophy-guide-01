Leonida Ledger is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a checklist whose progress is saved in the browser (with export and import), filters by kind and grade, a spoiler-free mode that hides story trophies until earned, a roadmap to the platinum built from the official descriptions, the possibly-missable trophies flagged, and a guide to each trophy — written in our own words, citing its sources, and honest about what is official fact versus what is still an estimate on the game's launch day.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the app is plain static files under `app/`, and it works with the network off.
